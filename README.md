A practical mini project for learning how to load, inspect, analyze, filter, and sort CSV datasets using Pandas. This project is part of my journey learning Python for AI and Data Science.

# Project Goal

The goal of this project was to work with a realistic customer dataset and practice the basic workflow used when analyzing a new CSV dataset.

The dataset contains information about customers, including:

- Customer ID
- Age
- Gender
- Monthly spending
- Number of purchases
- Satisfaction score

The dataset also contains missing values and a duplicate row intentionally, making it more similar to a real-world dataset.
